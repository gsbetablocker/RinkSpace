# 验证与结果判定

验证范围必须对应所声称的能力。代码运行、数值收敛、候选可查看、真实定位准确、同赛事复用和跨赛事通用是不同结论；单个节目或赛事通过不能证明所有花样滑冰转播可用。项目目标见 [README](../README.md)，选定快照见[离线审阅](GITHUB_REVIEW.md)，技术入口见[架构说明](ARCHITECTURE.md)。

历史实验的来源和失败结论留在原证据记录中，不作为当前能力认证。

## 机位与源时间

完整目标转播的镜头进入目录，逐段有源视频身份、起止 PTS、机位归属/未知状态、直播/回放/转场标签和安装时期。代表画面用于找镜头，完整镜头和时间表用于验覆盖；切镜数量、外观类别或挑图数量不能替代物理机位分类。

同机位判断结合静止场景传递与未参与拟合的冰面证据。非冰场、其他场馆和难分类镜头保留标签及覆盖分母。摇镜、变焦不自动产生新机位；相同广告内容不单独证明同机位。对安装移动、不确定分类和相反证据分别记录。

源帧与代理/诊断视频通过实际 PTS 对应核验，不用平均 FPS 推造时间。展示重复帧、独立曝光、官方源与回放的对应有源证明；已核实的 60 Hz 展示/50 Hz 曝光关系只适用于对应原片。每次验证声明采用展示帧还是独立曝光作分母，不能将重复曝光充作独立证据。

## 观测与独立性

观测审计保留原始源像素、物理结构/材料身份、人工确认、遮挡与不确定性，并区分直接测量、弱区间、传播、模型投影和先验。视觉评估使用未参与训练和调参的真实源镜头，检查边界位置、类型与实例身份，不能只看训练损失或模型自身投影一致性。

拟合、开发诊断和留出评估分别记录。同一物理结构的相邻像素、多帧轨迹、重复曝光、回放和不同 URL 的同画面不算独立地标。同一图案参与建图后，新帧可检查定位，但不能独立验证该图案的几何。评测前冻结模型、观测角色及判据，来源隔离涵盖全场、个人视频与回放的重复画面。对应检查观测及保护邻域不进入拟合、模型选择或阈值调整；用于修复的旧留出成为开发材料，不能继续作为独立通过证据。

评测前说明空间分布、时间覆盖、分辨率、标注不确定性和判据依据。地标数量由可辨识约束决定，不把一条圆环拆成多个独立物理组凑数。记录支持区域及外推范围，未观测区域和未知项明确保留。

## 共同模型与连续原片审阅

模型绑定源 PTS、赛事、机位/安装、模型版本与真实对应。检查冰面、围挡和广告是否使用求解实际几何；共享场景、逐曝光相机与镜头畸变分别检查。固定光心、米制尺寸和模板布局均需相应证据，不能靠求解满秩或小残差认定正确。

分别检查冰面边界、全部真实标记、三维围挡、广告实例/编号/拓扑/边界、相机与镜头。每个实体可追到源观测和已连接参数；身份确认、三维位置和像素边界准确性分别验收。归属未经原片确认的看台、人物、字幕、倒影或未知深度点不进入场地拟合。

连续看完整目标镜头，覆盖起中末、误差明显处、遮挡、缺失和切镜前后。左侧每帧投影同一套全部已建模网格、圈、Lane、其他冰面标记及广告框编号；右侧俯视图显示同一完整模型、广告位置与编号。线条不按检测成功、置信度或贴合好坏隐藏，未建模广告边不补造。截图仅作连续变化的时间标记。

完整视频每帧同时叠加该源曝光当前有效的实际取点，保留现有拟合网格信息；按源 PTS 对应，不用模型投影或其他帧的点补充。只显示当前点，不叠加历史点、剔除点、修改前后对照或额外点编号。取点核查与视觉模块覆盖所有已建模线条和边界的全部源帧；仅 F1–F4/R1–R4 八组靶圈的 center、inner、middle、outer 四层圆，以及半椭圆蓝区取轮廓；其他所有直曲线（包括 C0、A1–A4、Lane、连接线、球门线、梯形线）只有材料宽度中线定义，模型零线宽。禁止这些线的外/内轮廓定义、别名和兼容回退，未激活条目同样拒绝。

完整选定镜头的全部源帧进入覆盖记录，不通过裁短、只挑好帧或隐藏失败获得通过。缺失相机状态和无法定位帧计入相应分母，不能用全部 `unknown` 冒充能力。切镜及切回重新定位，局部修好不称为全场完成。

## 误差与尺度

二维材料点误差与曲线法向误差分别报告。图像椭圆中心、极值和任意弧采样不自动是材料点；轮廓贴合可能仍沿曲线错位，参考帧自比的零误差不进入独立统计。广告角点/边界与冰面标线共同检查投影，物理实例不能仅凭文字相同关联。

报告原始像素与缩放关系、分位数、尾部/最坏时刻、缺失分母及标注不确定性。不事后放宽判据回填通过，不用平滑程度代替准确性。

像素、透视、欧氏、条件米制和已验证米制分别表达。假定尺寸、型号规格、示意图或比例约束不会自动给出实测尺度；尺寸事实绑定本赛事来源。静止印刷图案可在核实后跨时期复用，冰面划痕、反光及更换后的广告另行处理。

## 通用性与复用

同赛事跨节目验证：共同场景保持冻结或明确记录更新，用未参与调参的完整节目镜头验证重新定位、时间对应及连续误差。同赛事跨机位验证覆盖对应安装与视角，而非只检共享参照帧。

跨赛事、冰场或转播验证：分别建立该赛事场景与机位数据，检查公共接口是否无需复制求解器或把赛事数值写成全局常量，随后验证真实完整镜头。报告实际覆盖的赛事、冰场布局、镜头条件和失败类型。只有开发样本的结果时，明确说通用目标尚未得到跨赛事验证。

## 选手位置、接触与统计

先核对测量对象：三维骨盆及其垂直投影、身体代理、视线与冰面交点、左右冰刀接触分别评价。二维骨盆像素经冰面映射不称为已验证垂直投影；依赖高度或人体假设时说明条件与误差。

真实接触按左右物理脚和点定义分段，腾空、遮挡、切镜及映射缺失不补成接触。速度、切线和曲率使用真实时间及相应几何等级，检查像素、标定、尺度与时间窗口扰动。共享标定误差作为相关误差处理。

回放不重复进入节目时长或事件计数，未知变速不计算原速导数。统计说明对象、尺度及可定位/不可定位分母；路线凸包不是实际覆盖，身体代理速度不能称为冰刀或重心实测速度。

## 工程验证与交付

修改后按受影响接口检查源身份、时间对应、模型版本、坐标域、物理 guard、失败处理及完整检查点续算。已有快版求解接口与完整状态优先复用；性能对照使用相同输入、状态与数学目标，数值等价/加速不能替代原片定位验收。

文件存在、静态检查、实际打开和连续播放分别记录。结果能返回真实源画面；模型、观测修正和验收结论可追溯。视频交付本地路径与源时间供 PotPlayer 播放；诊断复用已有材料，完整视频生成依据真实模型进步和当前交付需要。
