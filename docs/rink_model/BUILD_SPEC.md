# 通用冰场、围挡与相机模型接入

RinkSpace 的长期目标是适配所有花样滑冰转播，覆盖不同赛事、冰场、机位和节目。软件、模型数据结构与处理流程复用；冰场几何、全部广告实例、相机安装和成像参数分别属于经核实的赛事与场次。同赛事的节目引用共同模型，不为每个节目另建一份冰场；不同赛事不能直接共用同一组数值。

本文说明建模与接入的数据关系。长期规则见[AGENTS.md](../../AGENTS.md)，入口见[README.md](../../README.md)，技术出处见[技术来源](../SOURCES.md)。安卡拉与冈田芽衣是当前开发与验证样本，不能定义产品适用范围。

## 来源与机位目录

新赛事接入时建立源时间与机位目录，为共同模型和原视频定位提供依据；已有的分类、模型与完整状态直接复用，发现错误再纠正。目录保存源视频身份、原始 PTS 与 time base、镜头起止、物理机位候选、安装时期、分类依据和未确定项，交付各机位代表画面及全部镜头与源时间。摇镜、俯仰和变焦不自动产生新机位；回放、非冰场画面和其他场馆分别标记。代表画面用于导航，不能代替整场分类。

来源登记保留 URL、频道与赛事身份、场次、原片哈希、格式与尺寸、时间基、实际文件位置、代理与原片关系、切段偏移、重复画面组和证据角色。标题或关键词不能独自证明同赛事、同场馆或同安装。原片与代理分别记录，切段本地零点不能直接当原片时间。

全场、个人视频和回放中的同一画面按来源关系与帧证据识别，换 URL 不算新的独立观测。保留真实解码 PTS；展示帧率、重复展示帧与实际曝光分别记录，50/60 Hz 对应须来自该源的已核实画面证据，不能推广到所有转播。

## 赛事共同场景

共同场景包括冰面边界、实际存在的冰面标记、三维围挡、全部广告实例及其围挡关系、来源观测与版本。广告清单覆盖全部实例；未观测的边界或未确定的三维位置记录为缺失或候选，不能补造为已测量。重复品牌保留各自物理身份与编号。

冰面标记按真实场地登记。网格是分析坐标层，不能把赛事中不存在的冰球线、冰壶靶圈或 Lane 画成真实标记，也不硬套 60 × 30 米、统一圆角或左右对称。用户确认的结构关系与源观测保留出处；确认身份或拓扑不等于已经确认像素精度、三维坐标或米制尺度。

每个模型保存身份与 revision、所属赛事与场次、schema、坐标原点/方向/手性、单位与几何等级、结构实体、观测来源、相机安装、覆盖和已知歧义。每条观测绑定源哈希、原始 PTS、原图尺寸与像素坐标域、物理身份、采集方式、不确定性和用途。原片观测、人工确认、算法候选、传播结果与模型投影不能互换角色。

冰面、围挡和广告是不同空间实体。围挡底部与冰面的交界需明确几何定义；广告像素不能当作 Z=0 的地面点。圆环用真实轮廓约束，透视椭圆的图像中心不能直接当作物理圆心投影。广告参与位置、形状和相机约束，不能只保留它的方向。

几何证据覆盖、纹理实拍覆盖与定位验证覆盖分别登记。缺少视角的区域保留未知；条件外推标明依据。纹理拼图可作为共同几何的材质层，拼接清楚不能证明几何准确。

## 符合实际运动与成像的相机模型

物理机位、安装时期和每帧相机状态分开记录。同安装允许共享有证据支持的安装与镜头参数；每帧保存实际视向、俯仰、焦距及其他已采用参数。跨场次安装未经核实时保留候选关系。

相机模型应描述实际摇镜、俯仰、变焦、滚转、安装运动与镜头成像。固定光心、主点居中、零畸变或某一初始焦距只能作为明确的模型假设，不能写成项目默认事实。云台旋转中心与镜头光心可以不同，变焦也可能改变有效光心；新增自由度须说明证据、可识别性及未参与拟合的检查结果。

联合求解使用有真实身份与源时间的点、线、轮廓、围挡和广告观测。多画面通过共同实体连接，保留无法连接的分量；单个平面或重复广告的低残差不能证明机位、三维几何与尺度都正确。计算 gauge、尺度自由度和弱约束方向显式记录。

畸变、裁剪和缩放属于投影链。观测、求解、显示必须约定同一像素域；在原片绘制时重施实际采用的镜头畸变。畸变下的直线与广告边界应采样投影，不能仅连接端点。

## 节目引用与连续定位

节目输入引用所属赛事模型、明确版本、源身份和完整镜头目录。利用真实冰面、围挡与广告观测估计相机和视图对应；关键帧之间可复用已有运动与传播接口，并由新的观测约束漂移。切镜重估机位候选与相机状态，保留共同场景；回放维持独立角色和源时钟。

每帧结果绑定模型身份/revision、源哈希/PTS/time base、镜头、安装候选、投影链与像素域、使用的观测、传播来源、误差和未知状态。预测、候选与直接观测分别记录。长缺失、矛盾和身份歧义不能硬填成已定位结果。离线双向估计注明未来信息使用。

世界空间位置与图像像素、冰面射影坐标、欧氏任意单位和已验证米制分开。人体空间位置的垂直投影与像素射线直接交冰面也不同：骨盆高于冰面，须保留所用三维估计及其假设，不能把骨盆像素的地面交点冒充骨盆正下方。腾空、接触缺失、左右脚与回放分别处理；只有经过相应证据验证后才能声明冰刀接触、速度或覆盖结果。

## 原片审阅与能力边界

审阅使用同一模型与实际求解采用的几何，连续展示整个镜头。左侧每帧固定全开已建模的全部网格、实际冰面标记、围挡广告框与编号，不按检测成功、置信度或贴合好坏隐藏；右侧俯视图也显示同一套标记与广告位置、编号。未建模或缺失的广告边不补造。无法投影的帧保留并说明原因。

拟合支持区、独立验证区、外推区与未知状态通过标注说明，不能靠隐藏线条改善观感。截图是连续审阅中的时间标记，不能用挑好帧代替整镜头检查。模型没有明确进步时复用已有证据或小范围图片，不生成完整视频；需要交付视频时按长期规则给本地地址与源时间。

`scene_camera.py`、`joint_scene.py` 及相机扩展保存现有三维数学与求解接口；当前 selector、配置和部分数据准备仍含赛事特例，不能据此声称跨赛事运行已验证。`registration.py` 是二维候选基线，`rink_reference.py` 只提供旧二维矩阵桥接与记录校验，不能承担完整三维场景或准确性声明。具体接口见[架构](../ARCHITECTURE.md)，证据判定见[模型验证](../VALIDATION.md)。
