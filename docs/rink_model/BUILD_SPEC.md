# 通用冰场、围挡与相机模型接入

本文维护来源接入、场景语义和观测准入。赛事数值与人工事实归所属赛事，节目源时钟与范围归所属节目；接口和能力分别见 [INTERFACES](../INTERFACES.md)、[REBUILD](../REBUILD.md)，验收要求统一见 [VALIDATION](../VALIDATION.md)。安卡拉与冈田芽衣是开发样本，不能据此宣称跨赛事验证完成。

## 来源与机位目录

新场地接入先分机位，再建共同模型，最后接原片网格；复用已有分类、完整状态和公共接口，实际失败时修复。机位目录保存源身份、原生 PTS/time base、镜头范围、物理机位候选、安装时期、分类依据及未知项，交付各机位代表画面和全部镜头与源时间。摇镜、俯仰和变焦不自动产生新机位；回放、非冰场画面、其他场馆分别标记，代表图不能代替整场分类。

具体节目使用 ISU 官方 YouTube 频道的 50 帧单节目原视频和原生 PTS，不再使用 60 帧全场回放作为节目处理源。URL、哈希、表征、实际位置、源尺寸、裁剪/缩放与代理偏移登记在所属节目；历史全场及回放关系保留供追查。实际展示率、重复帧和独立曝光按源核实，不能从一个视频的 50/60 Hz 对应推广到其他转播。

标题、相同广告或换 URL 不独自证明同赛事、同安装或独立证据。切段本地零点不当作原片时间，实际 PTS 不用平均 FPS 重造。

## 赛事共同场景

同赛事、同布置时期的节目引用共同场景；不同赛事的冰场、广告和安装数值分别核实。场景包括实际冰面边界与标记、连续三维围挡、全部广告实例、结构关系、来源和版本。未观测边界、未定位实例及不能连接的分量保留未知，不补成已测量。

模型保存身份/revision/schema、赛事与时期、坐标原点/方向/手性、单位和几何等级、参数与来源、覆盖及歧义。网格是分析坐标层，不能把不存在的冰球线、靶圈或 Lane 画成真实标记，也不硬套标准尺寸、圆角或对称关系。结构或身份确认不代表像素、坐标和米制已通过。

冰面与围挡分属不同空间表面；广告像素不能当作 Z=0 地面点。围挡底边与冰面的交点须有明确几何关系，圆环的图像椭圆中心不是物理圆心投影。广告保留位置、形状与相机约束，不能只使用方向。几何、实拍纹理和定位验证覆盖分别记录；清楚的拼图不证明几何准确。

### 来源与观测准入

场地拟合只接收原片核实属于冰面或围挡本体的静止实体/材料。看台、人物、字幕、倒影、未知深度或归属未确认的点不进入当前场地拟合。

每条观测保留原 UV、源哈希、整数 PTS、像素域、实体与测量定义、采集方式、质量、相关组、用途及人工确认。直接测量、传播、投影和先验分别记录；低残差不能改变来源资格。

等价迁移保留原准入状态：既不因 legacy 标签一概禁用，也不因导入成功自动激活。属于已确认实体、通过来源/跟踪/模糊/遮挡检查的机器测量可按相同准入条件使用，不要求逐行人工签字。pending、rejected、synthetic 或非实测证据不能仅翻转 active 放行；低置信歧义按实体与时间簇处理，不能默认要求用户重新逐帧标注。字段及读取校验见 [INTERFACES](../INTERFACES.md#当前输入与-prepared)。

### 广告几何与取点

广告的“长方形”指整圈围挡剪开摊平后的展开面形状；三维表面随连续围挡延伸，可跨直段和弯段，不强制成为平面矩形。已确认等尺寸的实例共享相应尺寸，安装位置与离冰高度独立；同品牌不自动获得这种关系。

只建模常见可见画面中能稳定辨认、可靠对应的清晰文字和明确大轮廓。QR 小格、手机界面与细碎装饰保留参考，不进入当前模型与拟合；不能因单帧清楚就加入普遍难辨细节。已有字形外缘、内孔、面板边与明确图形按实际实例/模板/路径保留，取点仍须在该曝光可辨。

冰面实体编号和取点定义由赛事维护；当前安卡拉见[冰面取点定义](../../events/ankara_2026/scene/README.md#ice-observations)。广告材料轮廓不套用冰面中线规则。

## 符合实际运动与成像的相机模型

机位、安装时期与逐曝光状态分别记录；同型号不意味着共用现场数值，跨场次安装未经核实只保留候选关系。固定光心、居中主点、零畸变或初始焦距是待验证假设。云台支点与光心可不同，变焦可改变有效光心；已有 roll、轴间距、杆臂及入口瞳项按真实模型保留，未知族不能静默归零。

多画面以共同实体连接。活动参数须有相应覆盖与可辨识性依据，规约、尺度及弱约束方向显式记录；单平面或重复广告的低残差不能证明完整三维和内参正确。数值模型与滚动快门算法见 [SOLVER](../SOLVER.md)。

观测、求解与显示共用像素域及畸变/crop/resize 链。原片叠加重施实际镜头畸变；曲线及畸变后的直边采用采样投影，不能只连接端点。

## 节目引用与连续定位

节目引用赛事模型/revision、源身份和完整镜头目录，使用真实观测约束相机及传播漂移。切镜重新估计机位候选和状态，保持共同场景；回放保留独立角色和源时钟。

逐曝光结果绑定模型、源哈希/PTS/time base、镜头与安装、投影链、所用观测、传播来源、误差和未知状态。长缺失、身份歧义或矛盾不硬填为已定位；离线双向估计注明未来信息使用。空间等级、人体垂直投影与冰刀接触按[验证定义](../VALIDATION.md#选手位置接触与统计)分别判定。
