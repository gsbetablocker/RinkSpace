# 共同场景与连续定位的证据验证

RinkSpace 面向所有花样滑冰转播；验证须对应实际声称的赛事、冰场、机位、节目、空间区域与时间区间。单个开发节目或同赛事复用不能证明跨赛事通用能力。本文是技术判定参考，长期规则见[AGENTS.md](../../AGENTS.md)。

## 机位分类与场景完整性

已登记转播的完整镜头有可追溯目录，每段记录源身份、起止 PTS、机位归属或未确定状态。各机位交付代表画面、全部镜头与源时间表、安装关系、分类依据和相反证据。非冰场、其他场馆与回放分别标记，难分类镜头不能从覆盖分母中去掉。

摇镜和变焦不自动算新机位。同机位关系需由静止场景的画面传递、空间观测与未参与拟合的证据核实；广告相似、切镜编号或少量截图不能独自支撑结论。固定光心与跨场次安装不变也须单独验证。

共同模型分别检查冰面边界与实际标记、三维围挡、全部广告实例/编号/拓扑/边界、相机运动与镜头成像。能查看每个实体来自哪条源观测、哪些参数已连接、哪些仍是假设或缺失。广告身份确认、三维位置求解和像素边界准确性分别验收。缺失区域、不存在的标记与未经核实的米制不能补成完整模型。

## 独立证据与版本冻结

建图、开发诊断与锁定检验按真实物理实体和来源关系划分。同一圆环的多点、多帧和重复上传不能充作多个独立物理地标。图案参与建图后，在新帧核对可检查定位，但不构成该图案几何的独立验证。

留出节目与赛事保持来源隔离，识别全场、个人视频与回放中的重复画面。要声明跨赛事适配，须在未用于训练、建图或调参的其他赛事和场地条件上检查共同流程；各赛事使用自己的场景数值。要声明同赛事跨节目复用，须冻结场景几何后在未参与建图的节目上运行，清楚记录允许估计的相机参数与辅助人工输入。

在查看本次评测结果前确定版本、完整目标镜头、观测角色、判据及误差阈值依据。失败后的修复使用新版本并记录其留出关系，不能事后改判据回填通过。冻结是评测状态，不是禁止修复或暂停任务的指令。

## 真实原片对齐与连续性

评测保留完整选定镜头、原片 PTS/time base、切镜前后、最大误差与缺失区间。分母包含全部选定源帧，不只包含成功输出的帧。未知不是通过，平滑预测不是直接观测。

使用分布于声明有效区域的独立点、线、轮廓及不同空间表面的观测。点的二维误差、曲线法向误差、广告边界误差分别报告，附原始像素尺寸、模糊/标注不确定性、空间时间覆盖与最坏窗口。单一图案、低拟合残差或静止广角不能证明全冰场及移动、变焦镜头都准确。

定位结果必须有实际使用共同模型的对应链，包含模型实体、源观测、相机与镜头参数、投影域和版本。旧局部候选 H 不能包装后直接成为已验证的全局定位；不同模型版本混用应被识别。工程检查可确认接口关系，真实原片证据才能支持准确性结论。

连续审阅整镜头时，左侧每帧投影同一套全部已建模网格、真实冰面标记和广告边界/编号，右侧显示同一模型的全部标记与广告位置/编号；不按检测或贴合情况隐藏线条，不补造缺失广告边。截图只标记时间。未能定位或投影的帧保留状态与原因。

空间误差与连续性结果的单位须对应几何等级。欧氏任意单位不能称米，假设米制不能称已验证尺度。骨盆的世界垂直投影、像素射线交冰面与冰刀接触分别检查；腾空和接触缺失不能填成冰上轨迹，速度分析须使用已核实的源曝光时钟。

## 工程检查与交付

按实际改动检查接口、schema、模型身份、源时间和依赖。数据格式、数值测试和合成投影只能证明相应工程边界，不能替代识别、几何、跨节目或跨赛事的真实验证。未执行的检查与受限范围明确说明。

交付先给与当前任务对应的结果入口、真实误差与未知区间，并附源时间与证据来源。机位工作交镜头表，模型工作交共同图与来源，定位工作交原片审阅证据。复用已有材料；模型无明确进步时不生成完整视频。视频提供本地地址与源时间，供 PotPlayer 播放。

历史失败、被否决身份、人工确认与原始源证据保持可追溯，删除重复或过时说明页不改变这些记录，也不使旧未通过结果自动转为通过。
