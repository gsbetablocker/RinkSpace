- 对最大的 31 曝光分量，实际完成三个独立相机族×三个初值、两种现有相机对照、五个 aspect profile 点。
- 最大分量时间：**26.920–32.920 秒**；训练 1,184 条纹理轨迹、5,673 对匹配；留出 544 条纹理轨迹、2,819 对匹配。训练单应性筛后留出 2,662 对，另 157 对仍保留在全部留出口径内。

- 命令行 `refit` 的实际读入/输出/哈希检查已跑通；21 项自动测试通过。合成测试包含已知内参恢复、畸变往返、旋转约定、稀疏 Jacobian 结构、整轨迹划分、留出污染不影响拟合、纯变焦退化、平移残差、多分量旋转参考系、精确 PTS/参数导出合同和防覆盖。

## 最大分量真实结果

单位为原片像素；中位数 / P95 是双向像素转移误差。筛查口径一致，且只由训练单应性确定，不由各个相机候选自行删除难点。

| 模型 | 全部留出中位数 / P95 | 筛后留出中位数 / P95 | 关键状态 |
|---|---:|---:|---|
| 逐对一般单应性（图像运动参照） | 0.730 / 9.711 | 0.676 / 3.004 | 不是相机真值 |
| 方形像素＋中心主点 | 1.014 / 7.930 | 0.951 / 3.735 | 最优启动满足局部停止条件，但近单轴、覆盖不足 |
| 自由比例＋共享主点 | 0.801 / 6.980 | 0.754 / 3.098 | fx/fy 到 2.0 数值上界；不能接受 |
| 上述模型＋共享低阶径向项 | 0.788 / 6.872 | 0.740 / 3.065 | fx/fy 到 2.0 上界且预算内未收敛 |
| 原内参＋原瞬时旋转的中心模型近似 | 3.142 / 12.338 | 2.987 / 8.829 | 未计入原模型的光心平移/滚动曝光 |
| 冻结原内参、独立重估旋转 | 1.240 / 8.341 | 1.180 / 4.437 | 仍为中心模型近似，不是完整原生模型检验 |

各自原始留出 RMS 约 183 px，主要受未筛掉的明显错误匹配影响；它们没有被从数据文件删除。只引用约 0.7–1 px 的筛后中位数会掩盖这个事实，因此报告同时展示全部留出、筛后留出、拒绝数量和最大值。

**这次结果不支持直接替换主相机。** 自由模型把像素比例推到 2，并不是发现真实比例为 2；这是验证器必须拒绝“漂亮误差＝真相机”的实例。近单轴运动、占优平面、未建模的平移/滚动快门、特征误差和简化光学规律都可能参与补偿，当前试验没有把它们逐项分离。

五个固定 aspect 的 nuisance-refit 点均在 120 次预算内未收敛，全部保留。不能拿这条未收敛 profile 宣称已经确定最优比例或排除 1.0/1.357。也不能把这次 31 帧子集的失败推断为“整个已有转播无法识别相机”。

## 已得到的实用结果

1. 现有原片可以形成一条与冰场几何/主求解器无关的、可重复计算的图像证据路径。
2. 简单方形像素＋中心主点模型已能在这个子集上解释相当一部分背景运动；需要配合上述误差口径和假设阅读，不能据此验证全部主相机。
3. 自由度放开后出现触边，工具会如实报警，不输出可直接写回的“真实内参”。
4. 更多现有画面形成的多个分量可以参与共享光学检验，不必强行追踪同一个广告贯穿全段，也不需要用户重新拍摄。
