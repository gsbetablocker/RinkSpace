# 方法与结论边界

## 1. 本工具实际实现了什么

这是受 Sinha–Pollefeys 和旋转相机自标定研究启发的独立工程实现，不是原论文完整复现。原论文的宽视角全景采集与逐级变焦采集并不适用于用户无法控制的转播，因此本工具只从**现有转播片段**提取可用约束，不要求新增拍摄。

没有使用冰场几何、标注曲线对应、现有主求解器的投影函数、现有光学解的初值。已有相机 NPZ 只有在独立模型完成后才加载。图像特征及训练/留出分组不依赖生产相机结果。

## 2. 独立约束

假设静止场景、相同光心、瞬时全局曝光，世界/分量参考系到相机的旋转记为 R_i。没有畸变时：

    H_ji = K_j R_j R_i^T K_i^{-1}

有畸变时直接使用射线：

    ray_i = undistort(pixel_i, K_i, d_i)
    pixel_j_hat = project(K_j, d_j, R_j R_i^T ray_i)

同时计算反向预测，形成 4 维 residual。报告的每对标量误差为 sqrt((||e_ij||²+||e_ji||²)/2)，单位是原片像素。

这是直接最小化成对像素转移误差的共享相机优化；它没有实现论文的完整立方体全景、分层拼接或每条纹理方向的完整 bundle adjustment。不同边反复使用同一纹理会产生相关误差，因此不把 Jacobian 推导量当作独立同分布噪声下的统计置信区间。

每个图像连通分量的一个旋转固定为单位阵，以消除整体旋转规范自由度。分量之间不制造对应、不施加时间插值，只共享同机位的低维光学参数。

## 3. 候选族

共同前提：零 skew，焦距逐曝光独立变化，旋转逐曝光独立变化。不引入人体或冰场约束。

- `square_center`：fx=fy，主点在画面中心，无畸变。
- `square_pp`：fx=fy，估计跨帧共享的 cx、cy，无畸变。
- `free_pp`：估计共享主点与 eta=log(fx/fy)，无畸变。
- `free_pp_radial`：增加一个共享的画幅归一化径向系数 κ，并令 k1_i=κ(fy_i/W)²。k2=p1=p2=0。

最后一种只是控制自由度的对照族，既不是 Sony Z190 的实测变焦规律，也不是完整镜头标定模型。主点固定本身也是待检验假设；若实际主点随变焦变化，可能表现为候选失配。不能把候选失配自动归因于生产相机。

数值域：fy/W∈[0.2,30]；cx/W、cy/H∈[0.05,0.95]；fx/fy∈[0.5,2]；κ∈[-0.12,0.4]。这些不是厂家参数范围。触边明确报警；不得为取得“漂亮解”而静默放宽。根本目的不是穷尽 Z190 全光学自由度，而是提供可被反驳的受限独立参照。

畸变逆解使用二维 Newton 与往返误差、正 Jacobian 行列式检查。无效射线会进入失败统计，优化时受大惩罚，不能悄悄删除让误差变小。

## 4. 从已有视频取得对应

使用 ffprobe 原生显示顺序 PTS + ffmpeg 解码，不能用名义 FPS 推时间。S01 审核包的 stream-copy 片段存在预滚，必须按 source clock 限定源区间。原片及选中帧 BGR 哈希均核验。

SIFT → RootSIFT → 双向 ratio 匹配 → 连续至少三曝光的纹理轨迹。去掉同一位置的 SIFT 多方向重复；轨迹合并禁止同一帧两个不同关键点共用一个轨迹。

整条识别到的轨迹按确定性哈希划分约 70% 训练、30% 留出，之后才用训练轨迹估计单应性、决定边是否可靠。特征数量、分布与边筛选均不使用生产相机。

训练单应性用 RANSAC，阈值 5 px；宽松双向一致性筛查阈值 8 px。保留训练模型筛除的留出行并统计，不只交付好看的子集。空间分区限额降低单块文字区域的重复权重。RANSAC 与筛查仍可能偏好占优平面，不能证明特征横跨可靠深度。

同一纹理的分裂轨迹仍可能落入两组；这份检验不是独立采集或严格时间块留出。程序没有人物语义分割，不保证所有“背景候选”都静止。遮罩、鲁棒统计和人工少量核对图共同帮助发现问题。

## 5. 优化与可辨识性

SciPy `least_squares(method='trf', tr_solver='lsmr')`，稀疏数值 Jacobian，soft-L1（f_scale=2），有界局部多初值。默认初始 fy/W 为 1、3、8，仅从训练单应性估计相对变焦和旋转。用训练目标选择本族最优启动，不用留出误差挑启动。

报告终止原因、nfev、optimality、触边、各初值结果，以及尺度归一后的局部 Jacobian SVD。对共享参数再消去逐帧姿态/焦距方向，输出剩余弱方向。奇异值阈值与轴激励阈值只是工程报警，不是数学上的唯一可辨识证书。

可选 aspect profile 固定 eta，在每个网格点重新优化全部其它自由参数，不是冻结其它参数扫代价。它只从本族当前最优解做一次局部暖启动；可能未收敛，也可能错过其它极小值。所有 profile 行必须连同停止状态阅读，不能作为全局置信区间。

默认未包含全局优化、滚动快门标定、偏心云台或机械链拟合。这些不是偷偷遗漏后仍然声称求准的参数，而是本验证器明确不覆盖的项目。

## 6. 与 1ce8ae1 结果对照

只读 `camera_trajectory.npz`，要求 `source_pts` 精确匹配、`instantaneous_camera` 为 N×24、状态有效、旋转正交。列合同：R=4:13，C=13:16，fx/fy/cx/cy=16:20，k1/k2/p1/p2=20:24。正确读取实际 fx/fy，不使用旧诊断报告中错取下标的 `native_aspect_parameter`。

两种对照：

1. 原内参+原瞬时旋转：检查直接射线转移。
2. 固定原逐帧内参/畸变，重新拟合旋转：减少将姿态误差误归于光学的风险。

两者都忽略光心平移和滚动行时间，使用曝光参考时刻的相机快照；不能冒称是原生 `project_motion` 的等价计算。原模型本就含移动光心与约 19.43 ms readout，在这里更差的误差不足以单独判它错误。

## 7. 如何判读结果

`INCONCLUSIVE`：至少存在未收敛、触边、局部弱方向、单轴/近零旋转、过多拒绝匹配、时间覆盖不足、无效射线或条件模型失配等问题。

`CONDITIONAL_IMAGE_CONSISTENCY`：仅表示当前有限诊断没有报警且该简化模型能解释这些轨迹。仍不是完整相机通过，更不是主点/焦距已被唯一识别。

所有输出固定包含 `physical_camera_certified=false`、`altitude_identified=false`，不会以低误差自动生成可写回的“最终相机”。

## 8. 本工具怎样提供实际价值

把“冰场几何拟合得好”和“图像运动在另一组假设下是否支持该相机”分开；暴露不一致、触边与欠激励；在不同受限模型和现有内参之间提供同一批纹理上的比较；留下可复现数字和原片对应，而不是再多一套看似精确但未经检验的相机参数。

它不能单独确定相机高度、绝对尺度、机械杆臂或米制相机位置。它也不证明现有转播永远不足；这次失败只对应所用样本、匹配、模型族和优化预算，不是对所有既有画面信息的结论。
