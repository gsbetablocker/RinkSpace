# RinkSpace

RinkSpace 是一个研究花样滑冰转播空间分析的本地工具项目：从随镜头运动、变焦和切换的视频中恢复冰场、围挡、广告与相机的共同几何模型，再将选手运动连接到统一场地和原始视频时间轴。

项目目标是支持不同赛事、场地、机位和节目。安卡拉赛事与冈田芽衣节目是现有开发样本，不能直接代表对其他赛事的泛化效果。

## 研究内容

- **场地与相机建模**：共同冰面、连续围挡和广告展开面，以及分机位的相机安装、姿态与变焦参数。
- **来源可追溯的观测**：记录原生 PTS、源图、人工确认、材料边界和点位资格，区分真实观测、工作假设与推断。
- **求解与审阅工具**：几何拟合、场景渲染、原帧标注和连续镜头检查，保留失败状态与历史证据。
- **运动分析接口**：探索人体、轨迹、冰刀接触及速度分析，并区分身体参考点、世界垂直投影和真实接触。

## 当前状态

项目处于研究验证阶段。仓库已包含媒体时间审计、标注与审阅、几何求解、渲染及必要数据读取工具；完整节目定位和跨赛事通用能力仍未完成验收。

已有九镜头场地恢复快照保留为失败状态，统计输入的消费、源资格闭合和独立视觉验证仍有缺口。数值收敛、平滑结果或测试通过不代表场地准确。人体、GPU 和完整拟合运行还涉及独立环境、外部模型及来源材料，不能仅安装基础 Python 包就认定可以完整复现。

2026-10-21 已保存 S02–S06 共 3320 帧的取点与资格修订、共享源记录存储、恢复初值及求解和反馈工具更新。具体交付与数据边界见[后续开发进度](docs/GITHUB_REVIEW.md#后续开发进度2026-10-21)；共同物理模型仍待验证。

## 阅读与离线审阅

先读[架构与接口](docs/ARCHITECTURE.md)、[算法说明](docs/ALGORITHMS.md)和[验证方法](docs/VALIDATION.md)。具体模型、当前状态、配置及必要观测见[节目审阅目录](events/ankara_2026/programmes/okada_mei_sp/review/README.md)。

必要审阅数据使用少量 ZIP 和索引保存。下载完整仓库后，可用 Python 3.11 标准库检查归档，不需要本机原始数据目录或求解环境：

~~~console
python -B scripts/read_offline_review.py --check
~~~

该命令核对归档目录、成员及大小，不执行包内代码，也不批量解压。查询单项、读取数组及审阅边界见[离线审阅说明](docs/GITHUB_REVIEW.md)。原始完整视频和所有历史运行产物不随仓库提供；完整镜头的独立视觉验证仍需相应源视频。
